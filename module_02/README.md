## Description

An introduction to writing reliable Python programs through exception handling, input validation, and defensive programming.

This module focuses on anticipating unexpected conditions and handling errors gracefully rather than allowing programs to terminate unexpectedly.

## Concepts

- Syntax errors and runtime exceptions
- Built-in Python exceptions
- Exception handling with `try` and `except`
- Raising exceptions
- Custom exception classes
- Input and data validation
- Exception inheritance
- Resource cleanup using `finally`

## Instructions

Navigate to the desired exercise and execute its Python script:

```bash
python3 filename.py
```

Where applicable, experiment with both valid and invalid inputs to observe how the program responds to unexpected conditions.

## Learning Objectives

- Identify common programming errors.
- Handle unexpected situations gracefully.
- Validate data before processing.
- Design meaningful exception classes.
- Improve software reliability and predictability.
- Develop a defensive programming mindset.
