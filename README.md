## Instructions

### Prerequisites

- Python 3
- Git

### Clone the repository

```zsh
git clone https://github.com/st-mooks/42_amman_python.git
cd 42_amman_python
```

### Explore a module

```bash
cd module_00
```

Navigate to an exercise and execute the corresponding Python file using:

```bash
python3 filename.py
```
