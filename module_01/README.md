## Description

An exploration of object-oriented programming (OOP) in Python.

Building upon the fundamentals introduced in Module 00, this module explores how data and behaviour can be organized into objects to create structured, reusable, and maintainable software.

## Concepts

- Classes and objects
- Constructors and object initialization
- Instance attributes and methods
- Encapsulation
- Inheritance
- Method overriding
- Code reuse
- Python program entry points

## Instructions

Navigate to the desired exercise and execute its Python script:

```bash
python3 filename.py
```

## Learning Objectives

- Model real-world entities using classes and objects.
- Organize related data and behaviour within reusable components.
- Understand the relationship between parent and child classes.
- Apply encapsulation to manage object state.
- Develop modular and maintainable programs.
