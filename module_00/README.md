## Description

An introduction to Python programming through a series of progressively structured exercises.

This module focuses on developing the fundamental programming skills required to translate logical problems into functional Python programs.

## Concepts

- Variables and primitive data types
- Arithmetic and logical operators
- Conditional statements
- Loops and iteration
- Functions and parameters
- Input and output
- Recursion
- Basic type annotations

## Instructions

Navigate to the desired exercise and execute its Python script:

```bash
python3 filename.py
```

## Learning Objectives

- Understand Python syntax and program execution.
- Translate problem requirements into logical instructions.
- Structure reusable code using functions.
- Develop confidence in debugging simple programs.
- Establish good programming habits.
